# oop-labs

Object-oriented programming coursework — console applications, one lab per directory.

## Labs

| Lab | Topic | Language |
|-----|-------|----------|
| [lab01](./lab01) | Console applications: math tables, factorials, perfect numbers, text analysis | Ruby |
| [lab02](./lab02) | Classes and methods: text processor, unit converters, calculator, history | Ruby |

## Usage

Run any lab directly using Ruby:

```bash
ruby lab01/main.rb
ruby lab02/main.rb
```
